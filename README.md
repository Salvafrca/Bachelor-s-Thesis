# Bachelor-s-Thesis
Bachelor's thesis supervised by the Department of Mathematical Analysis at the University of Granada, focusing on the algebraic formalism required for quantum mechanics.

This thesis serves as an introduction to the mathematical foundations used to build the theory of quantum mechanics. It introduces the necessary algebraic structures alongside their historical context, beginning with the Hilbert space model and culminating in a framework based on Jordan algebras.

The entire project was written using $\LaTeX$. This repository contains the source code for both the thesis document and the presentation slides, along with their compiled PDF outputs.
